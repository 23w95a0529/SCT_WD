# To-Do App

## Overview
This is a simple To-Do web application that allows users to add, edit, delete, and mark tasks as completed.

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed

## Getting Started
To run the application, follow these steps:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd to-do-app
2. Open index.html in a web browser.

Technologies Used

HTML
CSS
JavaScript

Usage

i. Enter a task in the input field.
 ii. Click on "Add Task" to add it to the list.
  iii. Use the "Edit" button to change the task.
    iv. Use the "Delete" button to remove the task.
      v.Use the "Complete" button to mark the task as completed.
