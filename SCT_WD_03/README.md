# Tic Tac Toe Web Application

## Description
This is a simple Tic Tac Toe web application where two players can play against each other. The game keeps track of player moves and checks for winning conditions.

## Features
- Interactive game board
- Tracks game state
- Displays winning messages
- Option to restart the game

## Technologies Used
- HTML
- CSS
- JavaScript

## Getting Started
1. Clone the repository or download the files.
2. Open `index.html` in your web browser.
3. Enjoy the game!

## How to Play
- Click on any of the cells to place your mark (X or O).
- The game alternates between Player X and Player O.
- The first player to align three of their marks (horizontally, vertically, or diagonally) wins the game.
- Click the "Restart" button to start a new game.
